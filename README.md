# 股权穿透结构图生成器

本地化运行的纯前端 Web 工具：上传工商股权结构 Excel → 自动解析股权关系 → 按银行授信股权穿透规则筛选 → 生成符合银行报告规范、**可编辑**的 PowerPoint 股权结构图。

所有解析、计算与 PPT 生成均在浏览器本地完成，企业数据不会离开用户设备。

## 功能

- 上传 / 拖拽 `.xlsx` 文件，自动识别两种常见格式：
  - 分层级工商报告（“一级股东 / 二级股东 / ……”分页，含区块、控制路径，如启信宝报告）
  - 通用表格（字段别名自动映射：股东名称 / 投资人 / 投资方；持股比例 / 股权比例；被投资企业 / 企业名称；层级）
- 建立标准股权关系模型 `investor → investee → ratio`
- 银行授信穿透规则：
  - 第一层直接股东全部展示
  - 第二层起按持股比例阈值（默认 25%，可调）继续穿透
  - 自然人股东停止穿透
  - 境外公司（香港 / BVI / Limited 等）停止穿透
  - 股比不详、无股东信息自动标记停止
  - 循环持股自动截断
- 纵向正交布局：投资方在上、被投资企业在下，带箭头连接线；多股东汇聚为水平总线，禁止斜线 / 曲线 / 交叉
- 节点碰撞检测：公司框、文字、比例、连线无重叠
- 页面自适应：默认 16:9，内容过多自动扩大至 A3；仍放不下时按用户设置的合并阈值（默认 25%）合并低比例股东
- 生成可编辑 `.pptx`：公司节点为 Shape，名称 / 比例为 TextBox，关系为正交连接线，箭头为可编辑箭头（不生成图片）

## 本地运行

```bash
npm install
npm run dev
```

打开 Vite 输出的本地地址即可使用。

## 本地演示（不部署）

双击项目根目录的 `启动本地演示.bat`，会自动启动本地服务并打开浏览器
（http://localhost:5173）。上传工商股权 Excel → 调整穿透与版式选项 →
下载可编辑 PPT，全程在本地完成，不会上传任何数据。

生产构建预览：执行 `npm run build` 后运行 `npm run preview`，浏览器打开
http://localhost:4173，体验与线上部署一致的产物。

## 测试与验收

```bash
npm test
```

将真实工商 Excel 放到项目根目录后，`npm test` 会执行全流程验收（解析 → 穿透 → 布局 → 生成 PPT），并把样例 PPT 输出到 `out/` 目录。

## 部署（GitHub + Cloudflare Pages）

1. 将本目录推送到 GitHub 仓库。
2. Cloudflare Pages → Create project → 连接该仓库。
3. 构建配置：
   - Framework preset：`Vite`
   - Build command：`npm run build`
   - Build output directory：`dist`
4. 保存并部署。应用为纯静态站点，无服务器、无数据库、无任何后端依赖。

## 技术栈

React + TypeScript + Vite；Excel 解析使用 SheetJS（xlsx）；PPT 生成使用 PptxGenJS；图结构与布局为自实现。
